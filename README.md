# Firebase Cloud Firestore 온라인 방명록

Firebase Cloud Firestore를 데이터베이스로 사용하는 모던 반응형 웹 방명록입니다.

## 🚀 주요 기능
- **실시간 방명록 등록 및 조회**: 새 글이 등록되면 새로고침 없이 즉시 목록에 반영됩니다.
- **Cloudinary 이미지 첨부 기능**: 사진 첨부(클릭 또는 드래그 앤 드롭), 이미지 미리보기, 첨부 취소 및 카드 내 라이트박스(확대 보기) 지원.
- **최신순 자동 정렬**: 최근 작성한 글이 가장 위에 표시됩니다 (`orderBy('createdAt', 'desc')`).
- **입력 유효성 검사**: 이름 및 메시지가 비어있을 경우 경고 문구 및 테두리 강조 표시로 입력을 유도합니다.
- **반응형 UI**: 모바일, 태블릿, PC 등 모든 기기 해상도에 최적화된 깔끔하고 감성적인 디자인.
- **상대 시간 표기**: 방금 전, N분 전, N시간 전 또는 날짜/시간으로 직관적인 작성 시간 표시.
- **XSS 방지 처리**: 사용자가 입력한 특수문자 및 태그를 안전하게 이스케이프 처리.

---

## 💻 로컬에서 실행하는 방법

웹 브라우저의 ES Module 보안 정책(CORS)으로 인해, `file://` 경로로 직접 더블 클릭해 열기보다는 로컬 웹 서버 환경에서 열어주는 것이 좋습니다.

### 방법 1: VS Code Live Server 확장 프로그램 사용
1. VS Code에서 `index.html` 파일을 우클릭합니다.
2. **"Open with Live Server"**를 클릭합니다.

### 방법 2: Python 간이 서버 실행
터미널에서 아래 명령어를 실행 후 브라우저에서 `http://localhost:8000` 접속:
```bash
python -m http.server 8000
```

### 방법 3: Node.js (npx serve) 실행
```bash
npx serve .
```
